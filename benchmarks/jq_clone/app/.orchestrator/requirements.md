# Requirements — jq clone

## Product
A standalone implementation of the jq 1.7+ command-line JSON processor, written in Python 3 (stdlib only; `regex` optional is NOT used — regexes are translated onto `re`), launched as `./jq` from the workspace root. It implements the full jq language (lexer, parser, generator-based evaluator with path tracking), all builtins in `docs/manual.yml` (normative), the CLI options listed in the ticket, jq-style output formatting and error messages/exit codes. Ships with a pytest suite (unit tests per builtin, CLI tests, and every one of the 259 manual examples run end-to-end through `./jq`) and a README.

## Acceptance criteria
R1. `./jq` executable runs from workspace root; reads multiple concatenated JSON values from stdin or files; invalid JSON input gives `jq: error (at <stdin>:N): ...` and exit 2.
R2. Lexer/parser: full grammar with correct precedence (`|` < `,` < `//` (right) < `=`,`|=`,`+=`… (nonassoc) < `or` < `and` < comparisons < `+ -` < `* / %` < unary/postfix), `def`, `as` bindings, `reduce`, `foreach`, `if/elif/else/end` (else optional), `try/catch`, `label`, `?`, comments, `$__loc__`, `$__prog_args`-free; keywords usable as object keys / after `.`.
R3. Literals & construction: numbers (preserve literal canonical form such as `1.0`, `100000000000000000000`), strings with escapes and `\(interp)`, arrays, objects with all shorthand forms (`{a}`, `{$x}`, `{"a b"}`, `{(expr): v}`, `{@base64: ..}`, `{a: 1 | 2}`-restriction, `$__loc__`), key order of insertion in construction, sorted keys for `keys`/`tojson` unaffected; `-S` sorts.
R4. Paths: `.`, `..`, `.foo`, `."foo"`, `.["a"]`, `.[n]`, negative indices, slices `.[a:b]` on arrays/strings/null, `.[]`, `?`, `.foo.bar`, `.foo[]?`, `getpath/setpath/delpaths/paths/paths(f)/leaf_paths/path()/pick/del/to_entries/from_entries/with_entries`.
R5. Operators: arithmetic with jq semantics (null identity, object recursive `*`, string repeat `*` number, string split `/`, array subtraction, `%` integer truncation with errors for zero, division by zero error), comparison with jq type ordering (null<false<true<numbers<strings<arrays<objects), `and/or/not`, `//` incl. error suppression, `?//` destructuring alternatives, unary minus.
R6. Control: `if`, `try/catch`, `error`/`error(null)`, `.a?`, `label/break`, `limit/first/last/nth/until/while/repeat/range/1,2,3/recurse/recurse_down/env/$ENV/input/inputs/debug/stderr/input_line_number/halt/halt_error/$__prog_args`, `reduce`, `foreach` (2/3 arg), `limit(0)`, `isempty`, `error` message formats identical to jq (e.g. `Cannot index number with "a"`, `null (null) and ...`).
R7. Functions: defs with filter params and `$` params, closures, recursion, nested defs, shadowing, arity overloading, `def f: reduce ...`; variable scoping; destructuring patterns (arrays, objects, `$name` keys, nested).
R8. Assignment: `=`, `|=` (with `empty` deleting per 1.7 semantics), `+= -= *= /= %= //=`, complex LHS paths, `limit` in paths, `getpath` in paths, `first(f)`, `if` in paths, `//` in paths, `recurse`, `..|=`.
R9. Builtins (all from manual): length utf8bytelength not keys keys_unsorted values nulls booleans numbers strings arrays objects iterables scalars has in inside contains map map_values path del to_entries from_entries with_entries select empty error add any all flatten range floor sqrt pow log etc (all math), tostring tonumber type infinite nan isinfinite isnan isnormal isvalid sort sort_by group_by min max min_by max_by unique unique_by reverse contains indices index rindex startswith endswith combinations/0,1 ltrimstr rtrimstr trimstr trim ltrim rtrim explode implode split/1,2 join ascii_downcase ascii_upcase ascii while repeat until recurse env transpose bsearch tojson fromjson todate fromdate now dateadd datesub date strptime strftime strflocaltime mktime gmtime localtime todate dates, splits sub gsub test match capture scan (flags g i x n s l p), `ascii`, `@formats`, `input_filename`, `$ENV`, `splits`, `getpath`, `tostream fromstream truncate_stream`, `limit`, `getpath`, `walk`, `env`, `halt`, `halt_error`, `get_search_list`, `ltrimstr`, `significand drem ldexp scalb scalbln nearbyint trunc logb gamma lgamma tgamma lgamma_r frexp modf`, `abs`, `toarray`, `have_literal_numbers`, `have_decnum`, `pick`, `debug(msg)`, `scan($re; $flags)`, `splits`, `ascii`, `@uri`, `getpath`, `error(msg)`, `add(f)`, `limit`, `skip(n; f)`, `tojson`, `ltrimstr`, `min_by`, `SQL-style` (INDEX, GROUP... IN, INDEX/2, UNIQUE? as in manual), `getpath`, `input_line_number`, `splits`, `$__loc__`, `getpath`, `ascii`, `@sh`, `tojson`.
R10. String formats `@text @json @html @uri @csv @tsv @sh @base64 @base64d` with exact escaping rules, and `@fmt "string \(interp)"` applying format to interpolations.
R11. Regex: Oniguruma-style syntax mapped onto Python `re` (named groups `(?<n>..)`, `\h`, `\H`, POSIX brackets, `\A \z \Z`), flags g,i,x,s,n,l,p; match output objects (offset in codepoints, length, string, captures with name), empty-match handling for `gsub`, `sub` with named captures and multiple outputs.
R12. Dates: `strftime`, `strptime`, `mktime`, `gmtime`, `todate`, `fromdate`, `dateadd/datesub/date`, `localtime`, `strflocaltime` with broken-down-time arrays (seconds possibly fractional) exact to jq 1.7.
R13. Output: pretty (2-space default), `-c`, `--tab`, `--indent n` (0 = compact, max 7), `-r`, `-j`, `-a` (ASCII escapes with surrogate pairs), `-S`, `--seq`, `-C` colors accepted (jq 1.7.1 default colours), numbers: integers as-is, literals preserved canonical (`1.0`→`1.0`, `1e1000`→ `1.7976931348623157e+308`), doubles printed with 17 significant digits shortest-roundtrip form like jq 1.7 (`3.0e-5`? → `3e-05` style: exponent at least 2 digits), NaN→`null`, infinity → `1.7976931348623157e+308`.
R14. CLI: `-n -r -j -a -c -s -e -S --tab --indent --arg --argjson --slurpfile --rawfile --args --jsonargs -f/--from-file -R/--raw-input (with -s and -n) --seq --exit-status -h -V --stream --stream-errors? $ARGS $__prog_args $ENV, short-option clustering (`-nr`), program from first non-option positional, `-e` exit 1 for null/false last output, 4 when no output.
R15. Errors: runtime error → stderr `jq: error (at <file>:N): msg` and exit 5 (processing continues with next input); compile error → `jq: error: msg at <top-level>, line N:` + `jq: 1 compile error`, exit 3; usage errors exit 2; `error(obj)` non-string messages: `jq: error (at ...) (not a string): {...}`; `halt_error` semantics and exit codes; `try error("x") catch .`; `break` outside label is a compile error.
R16. Every example in `docs/manual.yml` (259) passes as an end-to-end test (program, input, all outputs compared as JSON values, plus text-compare on compact form where deterministic); cases involving `now`, `env`, `input_line_number`, `$__prog_args`, `ltrimstr` etc. handled sensibly.
R17. Tests: pytest suite in `tests/`, unit tests per builtin family, CLI option tests, error/exit-code tests, number-format tests; `make test` / `pytest` runs from clean checkout. README with install/run/test/design.

## Assumptions
- Language: Python 3.9+ stdlib only; `./jq` is a small shebang launcher importing package `jqpy/`.
- Target behaviour is jq 1.7.1/1.8 per the supplied manual (e.g. `ltrimstr`, `trim`, `abs`, `toarray`, `have_literal_numbers`, `pick`, `splits`, `getpath`, `limit`, `skip`, `ltrimstr`). Where the manual is silent, jq 1.7.1 behaviour is used.
- Big-number precision: numbers parsed to Python int/float; integer literals > 2^53 keep their canonical literal text when passed through unchanged; arithmetic converts to double.
- Oniguruma features not in Python `re` (e.g. `\h`, `\p{..}` simple classes, possessive quantifiers) are translated best-effort.
- `$__prog_args`, `getpath` on invalid raises jq-style errors. `localtime/strflocaltime/mktime` use the process TZ.
- `input_filename`, `ltrimstr` on non-strings return input unchanged.
- Evaluator performance: generator-based tree-walking with closure compilation; deep recursion handled by raising recursion limit and running in a thread with large stack.

## Test strategy
- tests/test_manual.py: parametrised over every example in docs/manual.yml (R16, and most of R2–R12) through the `./jq` subprocess (and an in-process fast path).
- tests/test_builtins_*.py: unit tests per builtin family with hand-derived expected values (R4–R12).
- tests/test_cli.py: options, exit codes, stderr messages, formatting (R1, R13–R15).
- tests/test_format.py: number/string formatting known vectors (R13).
